Elegante prozedurale Syntax. Modernste Java 25 Power.

Euphorix interpretiert OpenEuphoria (openeuphoria.org) – eine prozedurale Programmiersprache mit bemerkenswert einfacher, intuitiver Syntax und mächtigen Sequences. Kombiniert mit einer 65.536-Register-VM, Java 25 Loom Virtual Threads, CSP Channels, nativen Enterprise-Datenbanken und autarkem High-Density Web-Framework.

-- Autarker High-Density Webserver mit reaktiven Patches & Mobile Grid
include std/vsui.e as vsui

integer app = vsui:app("ERP Cockpit", 8089)

function on_speichern(sequence ctx)
    sequence kdnr = vsui:val(ctx, "txt_kdnr")
    sequence name = vsui:val(ctx, "txt_name")
    
    -- Schneller Daten-Patch (flackerfreies Client-Rendering ohne Reload)
    return vsui:updates({
        vsui:grid_set_data("grid_kunden", {{kdnr, name, "Aktiv"}}),
        vsui:clear_form("form_kunden"),
        vsui:set_focus("txt_kdnr"),
        vsui:toast_show("Kunde erfolgreich gespeichert!", vsui:TOAST_SUCCESS)
    })
end function

vsui:on_click(app, "btn_save", routine_id("on_speichern"))
vsui:run(app)
-- Concurrency mit Java 25 Loom Virtual Threads & CSP Channels
include std/thread.e as thread
include std/channel.e as chan

integer ch = chan:new(10)

procedure worker(integer id)
    for i = 1 to 1000 do
        chan:send(ch, {id, i, i * 2})
    end for
end procedure

-- Starte 50 parallele Virtual Threads (extrem leichtgewichtig)
for w = 1 to 50 do
    thread:spawn(routine_id("worker"), {w})
end for

Architektur & Highlights

Euphorix vereint bewährte prozedurale Sprachkonzepte mit modernster Compiler- & VM-Technologie für datenintensive Geschäftsanwendungen.

Prozedural & Klare Syntax

OpenEuphoria ist eine moderne, rein prozedurale Programmiersprache ohne schwerfällige Objekt-Boilerplate. Universelle, dynamische Sequences als primäre Datenstruktur ermöglichen intuitive, robuste und blitzschnelle Programme. Sprachspezifikation auf openeuphoria.org.

Register-VM & AOT-Bytecode (.exb)

Clean-Room Register-VM mit Ahead-of-Time Bytecode-Kompilierung: 10x schnellere Startzeit (24 ms), voller Quellcode-Schutz (IP-Protection) und dedizierte, minimierte runtime.jar ohne Compiler.

Loom Virtual Threads

Mühelos skalierbare Nebenläufigkeit ohne Callback-Hölle: Millionen leichtgewichtiger Java 25 Threads, Async/Await und CSP Channels.

High-Density Web-UI (VS-UI)

Autarkes Webframework (HTMX & Vaadin Fusion): 22 Komponenten in html/lib2/, kaufmännische NumInputs (DIN 5008), Sticky-Header DataGrid und flackerfreie Partial-Updates.

52 MB Autarkes Single-Binary

Zero-Dependency Linux-Executable: Bettet Mini-JRE, runtime.jar, Webserver und alle 22 VS-UI-Assets fest ein. Kein Java nötig, läuft sofort – ideal hinter lighttpd oder Nginx.

Enterprise-DB & 861 Routinen

SQLite 3.47 & PostgreSQL (JDBC), UTF-8 Unicode, RFC 9535 JSONPath, XML DOM/XPath, Swing-Desktop-GUI und 74 vollständige Standard-Module.
